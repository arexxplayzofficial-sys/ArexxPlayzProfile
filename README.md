# 🎮 Arexx Playz Profile Website

A modern gaming-inspired personal profile website featuring premium UI, glassmorphism, smooth animations, and responsive design.

![Banner](images/banner.jpg)

---

## ✨ Features

- 🎨 Premium Gaming UI
- 🌌 Animated Hero Banner
- 💎 Glassmorphism Design
- 👤 About Page
- 🌐 Social Links
- 📊 Statistics Page
- 🧵 Threads Page
- 📱 Fully Responsive
- ⚡ Smooth Animations
- 🔥 Hover Effects
- 🌙 Dark Theme
- 🎯 Fast Loading

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/profile-website.git
```

Open:

```text
index.html
```

in your browser.

## 🎨 Customization

Replace these files:

```text
images/banner.jpg
images/profile.png
images/threads-banner.jpg
```

Update your social links in the HTML files:

- Discord
- Instagram
- Facebook
- YouTube
- Threads
